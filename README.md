# Brain-States-Dynamic-Regulation-with-DNN
This is the code for **Exploring the dynamic regulation mechanism of drugs on brain state transition from energy landscape**
The code is modified from the code in article **Revealing neural dynamical structure of C. elegans with deep learning**, and R. Zhou, Y. Yu and C. Li is its author. DOI: _https://doi.org/10.1016/j.isci.2024.109759_
