# Brain-States-Dynamic-Regulation-with-DNN
This is the code for **Exploring the dynamic regulation mechanism of drugs on brain state transition from energy landscape**.

This project is based on the original work: **Revealing neural dynamical structure of C. elegans with deep learning**, and R. Zhou, Y. Yu and C. Li is its author. DOI: _https://doi.org/10.1016/j.isci.2024.109759_

We would like to thank Zhou et.al for their sharing and helping.
